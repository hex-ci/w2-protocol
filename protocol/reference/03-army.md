# 军队与训练

> 14 个命令（cmd 3001 ~ 3015）。所有响应均以 1 字节 status 打头，成功值见各条目。

### `cmd=3001` — 训练军队

**请求参数**（按序拼接为 AES 明文）:

| 顺序 | 类型 | 字段 | 说明 |
|---|---|---|---|
| 1 | u64 | `building_id` | 建筑实例 ID |
| 2 | u32 | `army_id` | 兵种 ID |
| 3 | u32 | `amount` | 数量 |

**响应**: 无业务数据。status 为 **1** 时成功；失败时为状态字节 + 错误文案。
